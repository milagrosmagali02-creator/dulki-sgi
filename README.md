# Dulkí S.A. – Sistema de Gestión de Inventario (SGI)

Trabajo Práctico Integrador (TPI) de **Organización Empresarial**, Tecnicatura Universitaria en Programación a Distancia – Universidad Tecnológica Nacional (UTN).

## Descripción

Dulkí S.A. es una empresa ficticia que elabora alfajores artesanales, con planta en la zona sur del GBA y oficinas en CABA. Este repositorio documenta la Entrega N.º 4 del TPI: el modelado del proceso de **reposición de stock** que automatiza el Sistema de Gestión de Inventario (SGI), junto con la gestión colaborativa del proyecto y los mecanismos de control.
